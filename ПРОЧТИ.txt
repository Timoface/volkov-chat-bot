НАВИГАТОР КОМПАНИИ — вариант «исходный код» (для доработки)

Нужно: Node.js версии 24 или новее — https://nodejs.org

Быстрый запуск на Windows:
  Двойной щелчок по start-dev-windows.bat — сам установит пакеты (первый раз 1–3 минуты)
  и откроет http://127.0.0.1:5175

Вручную (любая система):
  npm ci                 — установить пакеты точно по package-lock.json
  npm run dev            — режим разработки, http://127.0.0.1:5175
  npm run build          — собрать сайт в dist/
  npm start              — запустить собранный сайт с сервером, http://localhost:8080
  npm run build:single   — собрать всё в один HTML-файл (dist-single/index.html)
  npm run model          — пересобрать 3D-модель .GLB

Нейросеть: скопируйте .env.example в .env.local и впишите DAHL_API_KEY.
Подробности об устройстве проекта — в README.md.

Все имена, кабинеты и телефоны в базе знаний — демонстрационные.
