Решение

Как работает «Навигатор»

1

Вопрос

Сотрудник пишет своими словами

2

Профиль доступа

Производство, офис или руководитель

3

База знаний

Только действующие и разрешённые документы

4

Нейросеть

GLM-5.3-Flash пишет ответ по базе

5

Ответ

Плюс карточка: кто, кабинет, телефон

Итог: ответ за секунды — или точный адрес нужного специалиста.

Схема работы. Сотрудник задаёт вопрос своими словами. Выбирает профиль доступа. Сервер отбирает из базы знаний только действующие документы, которые этому профилю разрешены. Нейросеть пишет по ним короткий ответ. Сайт добавляет карточку специалиста: имя, кабинет, телефон и часы приёма.
