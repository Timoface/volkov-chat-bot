НАВИГАТОР КОМПАНИИ — вариант «для хостинга» (статический сайт)

Эту папку можно выложить на любой статический хостинг, сайт будет открываться по ссылке:
  - Netlify: https://app.netlify.com/drop — перетащите папку целиком;
  - GitHub Pages, Cloudflare Pages, Vercel, обычный веб-сервер (nginx, Apache).
Сайт должен лежать в корне домена (адреса файлов начинаются с /assets/).

Открыть index.html двойным щелчком НЕ получится — браузер не загрузит модули с диска.
Для просмотра на своём компьютере используйте вариант «один HTML-файл»
или запустите любой локальный сервер в этой папке, например:  npx serve .

В этом варианте нет нейросети: чат отвечает по встроенной базе знаний.
Для нейросети нужен вариант «с нейросетью» (там есть сервер, который хранит ключ API).

Все имена, кабинеты и телефоны в базе знаний — демонстрационные.
