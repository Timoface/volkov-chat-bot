Технологии

Из чего собран проект

ЧастьТехнологии
СайтReact, TypeScript, Vite
ИнтерфейсAstryx (чат), shadcn/ui на Base UI, Tailwind CSS
3D-сценаthree.js (WebGL), своя программа-генератор модели .GLB
НейросетьGLM-5.3-Flash через Dahl API, сервер на Node.js
ПубликацияCloudflare Tunnel — ссылка для любого компьютера
Сайт написан на React и TypeScript. Интерфейс чата — на библиотеке компонентов Astryx, всплывающая панель — на shadcn. 3D-сцена работает на three.js, а саму модель создаёт моя программа. Нейросеть подключена через сервер на Node.js, чтобы ключ не попадал в браузер. Для показа сайт публикуется через Cloudflare Tunnel.
