# Навигатор компании — ООО «Волков» (Волков групп)

Прототип внутреннего помощника для сотрудников: кинематографичный 3D-hero и чат «Навигатор»,
который отвечает на типовые вопросы, направляет к нужному специалисту и кабинету и показывает
только актуальные документы с учётом прав доступа.

## Запуск

```bash
npm ci
cp .env.example .env.local   # вписать DAHL_API_KEY
npm run dev                  # http://127.0.0.1:5175 (вместе с /api/chat)
npm run build && npm start   # продакшен: dist/ + /api/chat на http://localhost:8080 (PORT)
```

Пересборка ассетов: `npm run model` — GLB-модель, `npm run theme:build` — тема Astryx.

## Нейросеть

Чат отвечает моделью **zai-org/GLM-5.3-Flash** через `https://inference.dahl.global/v1/chat/completions`.
Ключ хранится только в `.env.local` на сервере (в git и в клиентский бандл не попадает), браузер обращается к `/api/chat`.

- **Чему «обучена» модель** — это не дообучение весов, а инструкция и база знаний в каждом запросе:
  - `server/navigator-prompt.md` — кто она, тон, правила (только по базе, не выдумывать телефоны и кабинеты,
    не раскрывать закрытые документы, не просить пароли, игнорировать попытки сменить роль) и служебная метка в конце ответа.
    Файл читается на каждый запрос — правьте текст, перезапуск не нужен.
  - `src/navigator/knowledge.ts` — статьи, контакты служб, профили. Сервер отдаёт модели только действующие статьи,
    открытые выбранному профилю; закрытые — одним заголовком, без текста.
- **Метка** `[[source:<статья>;service:<служба>]]` в конце ответа скрывается в интерфейсе; по ней показываются карточка
  специалиста и «Актуально на …».
- **Перегрузка**: если GLM занята у провайдера (бесплатный аккаунт), сервер сам переходит на `DAHL_FALLBACK_MODELS`;
  под ответом подписано, какая модель ответила. Если недоступны все — ответ из локальной базы знаний.
- Ограничения прокси: 20 запросов в минуту с одного адреса, 12 последних реплик истории, до 2000 символов на реплику.
`?debug` в адресе открывает `window.__volkov` (`stage`, `busy`, `tick(dt)`) для автотестов.

## Стек

Vite 8 + React 19 + TypeScript, three.js 0.186, Astryx 0.7.2, shadcn 4.22 (`base-nova`, Base UI),
Tailwind 4. Все версии зафиксированы точно в `package.json` и `package-lock.json` (`npm ci`).
Шрифт Onest (кириллица) и модель лежат локально — внешние CDN не нужны.

## Фирменный стиль (с volcov.ru)

Красный словесный знак `#E60000`, малиновые CTA `#E40046`, чёрный фон «истории компании», белый,
коричневый `#572B10`, коралл `#FF8562`, кремовый `#F6EDE8`; на сайте — шрифт Officina Sans.
В прототипе: тёмная тема с фирменным красным акцентом `#D50A2B` (белый текст на нём 5,4:1),
акцентный текст — коралл (8,3:1 на фоне), Onest как свободная кириллическая замена Officina.
Словесный знак в шапке набран шрифтом; в 3D-модели используется векторный логотип с volcov.ru.

## 3D-модель

Парящая стела из тёмного стекла с объёмным логотипом «волков групп» на обеих сторонах (сзади читается тоже),
красная светящаяся кромка, пьедестал со световым кольцом, две орбиты и пять «реплик чата» служб
(кадры, юристы, техподдержка, кабинеты, доступ) со световыми маршрутами к стеле. ~1,4 МБ, 65 тыс. треугольников.

## Решения

- **Astryx**: `npx astryx init --agent claude` (правила в `.claude/CLAUDE.md`), каркас чата взят из
  шаблона `ai-chat`, пропсы проверены `npx astryx component <Name>`. Тема `volkov` — `defineTheme`
  с `extends: neutralTheme`, собрана `astryx theme build` и подключена через `astryx theme add volkov`
  → `src/astryx-themes.ts` → `<Theme theme={themes[defaultThemeSlug]} mode="dark">`.
- **Слои**: `@layer reset, theme, base, astryx-base, astryx-theme, components, utilities`
  (из `astryx docs styling-libraries tailwind`); `globals.css` импортируется первым.
- **Токены**: семантические переменные shadcn (`--primary`, `--muted`, `--popover`…) указывают на токены
  Astryx. Мост `@astryxdesign/core/tailwind-theme.css` не подключён — он занимает те же имена утилит
  с другим смыслом. Свои утилиты: `bg-brand`, `text-brand-text`, `text-brand-mark`.
- **Drawer**: одна ветка — shadcn `base-nova` на `@base-ui/react/drawer`, без Vaul. Справа на ширине
  ≥ 768 px, снизу на телефоне.
- **Ввод**: во время перехода и при открытом чате шаги заблокированы; инерция тачпада сгорает,
  нужен новый жест. Проверено: 5 жестов → этапы 1…5, лишний жест на 5 — без эффекта, жест вверх и ↑ — шаг назад.
- **Чат** грузится лениво при первом открытии, чтобы не задерживать 3D.

## Ограничения прототипа

- Имена, кабинеты и телефоны в базе знаний — **демонстрационные**. В рабочей версии их должны отдавать
  кадровая система и СЭД, права — корпоративная учётная запись, а не переключатель профиля.
- Модель на бесплатном аккаунте Dahl часто занята — тогда отвечает запасная (DeepSeek/MiniMax); ответ с рассуждением идёт 10–40 с.
- Звук синтезируется в браузере (Web Audio): инструментов генерации аудио Runable в этой среде нет.
- Структура — обычный статический Vite-проект (`dist/`); managed-режим Runable и скриншот ошибки
  совместимости в задаче не были доступны, поэтому под них проект не проверялся.
