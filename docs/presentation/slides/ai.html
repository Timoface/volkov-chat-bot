Ключ API хранится только на сервере

Модель я не переобучал — это дорого и долго. Вместо этого в каждый запрос сервер подставляет инструкцию и базу знаний. Инструкция задаёт роль, тон и правила. База знаний — только разрешённые профилю документы. В конце ответа модель ставит служебную метку, по которой сайт показывает карточку специалиста. Если модель перегружена, сервер переключается на запасную, а если недоступны все — отвечает по базе знаний. Ключ API хранится только на сервере.
